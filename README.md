# FCP - Excel 数据分类工具

按第一个 Excel 文件中指定列的类别列表，对第二个 Excel 文件指定列进行匹配分类，每个类别输出到一个独立的 sheet，并提取整行数据。支持精确匹配、包含匹配和模糊匹配。

## 功能特性

- **自定义列号** — 支持 Excel 列字母格式（A, B, C, ..., Z, AA, AB...）
- **行范围控制** — 通过行号指定每个文件参与处理的数据行范围（Excel 行号）
- **整行提取** — 匹配成功后输出整行数据，而非仅匹配列
- **三级匹配策略**（优先级从高到低）：
  1. **精确匹配** — 标准化后完全一致
  2. **包含匹配** — 类别名包含在值中，或值包含在类别名中（选更长/更具体的类别）
  3. **模糊匹配** — 使用 `rapidfuzz` 进行相似度匹配，可配置阈值
- **图形界面 / 命令行** — 默认启动 GUI，也支持命令行模式
- **调试模式** — `--debug` 在控制台打印详细调试日志

## 安装依赖

```bash
pip install -r requirements.txt
```

| 包 | 说明 |
|---|---|
| `pandas` | 数据读取与处理 |

## 使用方法

### 图形界面（默认）

```bash
# 启动图形界面
python fcp.py

# 调试模式（控制台打印调试日志）
python fcp.py --debug
```

界面操作：

1. **选择类别文件**：点击"浏览..."选择包含类别列表的 Excel 文件（文件1）
2. **选择数据文件**：点击"浏览..."选择包含待分类数据的 Excel 文件（文件2）
3. **设置文件1**：
   - **类别列号**：指定类别所在的列（Excel 列字母，如 A, B, C）
   - **行范围**：指定类别数据的起始行和终止行（Excel 行号，留空表示全部）
4. **设置文件2**：
   - **匹配列号**：指定待匹配数据所在的列（Excel 列字母，如 A, B, C）
   - **行范围**：指定待分类数据的起始行和终止行（Excel 行号，留空表示全部）
5. **设置输出文件**：指定输出 Excel 文件路径
6. **设置模糊匹配阈值**（可选）：默认 70，中文建议 60-70
7. 点击**"开始分类"**按钮，等待处理完成

### 命令行模式

```bash
# 基本用法
python fcp.py --cli 11.xlsx 22.xlsx -o classified.xlsx

# 指定列号和行范围
python fcp.py --cli 11.xlsx 22.xlsx --col1 C --col2 D --rows1 1,100 --rows2 2,500 -o out.xlsx

# 命令行 + 调试模式
python fcp.py --cli --debug 11.xlsx 22.xlsx --col1 A --col2 B
```

### 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--cli` | 使用命令行模式（不带则启动 GUI） | — |
| `--debug` | 调试模式，在控制台打印详细日志 | 否 |
| `file1` | 第一个 Excel 文件（类别文件，CLI 必填） | — |
| `file2` | 第二个 Excel 文件（数据文件，CLI 必填） | — |
| `--col1` | 文件1中类别列的列号（Excel格式，如 A, B, C） | `A` |
| `--col2` | 文件2中待匹配列的列号（Excel格式，如 A, B, C） | `B` |
| `--rows1` | 文件1的行范围，格式 `起始行,终止行`（Excel行号） | 全部 |
| `--rows2` | 文件2的行范围，格式 `起始行,终止行`（Excel行号） | 全部 |
| `-o, --output` | 输出文件路径 | `classified.xlsx` |
| `-t, --threshold` | 模糊匹配阈值（0-100） | `70` |
| `--skip-empty` | 跳过没有匹配行的类别 sheet | 否 |
| `--unmatched-sheet` | 未匹配行的 sheet 名称 | `未匹配` |

## 列号说明

列号使用 **Excel 列字母格式**：

| 列号 | 索引 | 说明 |
|------|------|------|
| A | 0 | 第1列 |
| B | 1 | 第2列 |
| C | 2 | 第3列 |
| ... | ... | ... |
| Z | 25 | 第26列 |
| AA | 26 | 第27列 |
| AB | 27 | 第28列 |

## 行范围说明

行范围使用 **Excel 行号**（从 1 开始计数）：

**文件1（类别文件）和文件2（数据文件）**：
- 第 1 行 = 表头（header），pandas 读取时自动消费，不参与数据处理
- 数据行从第 2 行开始
- 起始行最小为 2
- 终止行包含在内（闭区间）
- 如果终止行超出实际数据行数，自动截断到末尾

```
Excel 行号:  1    2    3    4   ...   N
            表头  数据1 数据2 数据3      数据N-1
```

**示例**：
- `--rows1 2,100`：文件1 取 Excel 第2~100行（共99行数据）
- `--rows2 2,500`：文件2 取 Excel 第2~500行（共499行数据）

## 匹配逻辑详解

对于文件2中每一行的匹配列值，按以下顺序尝试匹配：

1. **精确匹配**：将值与所有类别标准化（去空格、转小写）后比较，完全一致则命中（得分 100）
2. **包含匹配**：检查类别名是否包含在值中，或值是否包含在类别名中。如有多个命中，选择更长（更具体）的类别（得分 100）
3. **模糊匹配**：使用 `rapidfuzz.fuzz.WRatio` 计算相似度，得分 ≥ 阈值则命中。未安装 `rapidfuzz` 时使用 `difflib.SequenceMatcher`

## 输出格式

生成的 Excel 文件中：
- 每个类别对应一个 sheet，sheet 名称为类别名
- 未匹配到任何类别的行放入「未匹配」sheet
- **每个 sheet 包含文件2的整行数据**（所有列）

## 打包为 EXE

使用 PyInstaller 打包为独立可执行文件：

```bash
# 安装 PyInstaller（如果未安装）
pip install pyinstaller

# 执行打包
python build.py
```

打包完成后，可执行文件位于 `dist/fcp.exe`。

**打包选项说明**：
- `--onefile`：单文件模式，所有依赖打包到一个文件
- `--windowed`：GUI 模式，运行时不显示控制台窗口
- 自动包含 `rapidfuzz`、`pandas`、`openpyxl`、`tkinter` 等依赖

**错误处理**：
- GUI 模式下如发生未预期错误，会弹出错误对话框并保存 `error.log`
- CLI 模式下错误信息直接输出到控制台

## 性能

在典型硬件上（i5 级别 CPU）：

| 数据规模 | 类别数 | 数据行数 | 处理时间 |
|----------|--------|----------|----------|
| 小规模 | 10 | 1,000 | < 1 秒 |
| 中规模 | 50 | 5,000 | ~3 秒 |
| 大规模 | 100 | 10,000 | ~6 秒 |

**性能优化措施**：
- 使用 `itertuples()` 替代 `iterrows()`，行遍历速度提升约 100 倍
- 精确匹配使用字典查找（O(1)），避免线性扫描（O(n)）
- 预计算归一化类别，避免重复计算
- 相同值的匹配结果会被缓存，避免重复匹配
